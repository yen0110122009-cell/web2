# Tham chiếu GitHub Pages

GitHub ghi nhận rằng ứng dụng cần một quy trình build riêng nên được xuất bản bằng **GitHub Actions**, thay vì phục vụ trực tiếp mã nguồn từ nhánh. Điều này phù hợp với ứng dụng React/Vite vì tệp TypeScript/TSX cần được biên dịch thành tài nguyên tĩnh trước khi đưa lên Pages.

Nguồn chính thức: [Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), truy cập ngày 17-08-2026.
